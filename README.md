Wisconsin Housing ML

Учебный проект по машинному обучению: построение линейной регрессии, классификации и дерева решений на данных о недвижимости штата Висконсин.

О датасете

Датасет Wisconsin Real Estate Data 2026 — 12 643 объявления о продаже недвижимости, собранные с реальных сайтов в первом квартале 2026 года.

Источник: Kaggle — Wisconsin Real Estate Data 2026

Особенность датасета в том, что он не "причёсан" под учебные цели — в нём есть реальные пропуски, связанные со структурой данных (например, у земельных участков логично отсутствуют спальни, ванные комнаты и этажность, так как на них нет здания).

Задачи проекта
Линейная регрессия — предсказание точной цены объекта (listPrice)
Классификация — определение, относится ли объект к категории "дорогой" или "дешёвый" (порог — медиана цены)
Дерево решений — классификация "дорого/дёшево" и сравнение с логистической регрессией
Подготовка данных
Удалена колонка sub_type (89% пропусков — колонка практически бесполезна)
Удалена колонка text (текстовое описание объявления не используется в моделях)
Пропуски в sqft, beds, baths, baths_full, baths_full_calc, stories, garage заполнены нулями для объектов типа land (у участков земли действительно нет этих характеристик)
Для остальных типов недвижимости пропуски в этих колонках заполнены медианой
year_built заполнен медианой только там, где здание есть; для земельных участков год постройки оставлен пустым, так как заполнять его не имеет смысла
Удалены выбросы по цене: объекты дешевле $1000 и дороже $5,000,000 (44 строки, 0.35% данных) — их наличие сильно искажало результаты линейной регрессии
Категориальный признак type преобразован в числовой формат через One-Hot Encoding
Результаты
Линейная регрессия

Предсказание точной цены объекта.

Метрика	Значение
RMSE	~346 260
R²	0.353

Модель неплохо справляется с объектами среднего ценового диапазона, но систематически занижает цену для дорогой недвижимости (выше $1.5 млн) — вероятно, из-за нехватки таких объектов в обучающих данных.

Классификация (логистическая регрессия)

Порог: listPrice >= медиана (~310 000) → класс "дорогая" (1), иначе "дешёвая" (0). Классы получились сбалансированными (6308 против 6291).

Метрика	Значение
Accuracy	0.819
Precision (класс "дорогая")	0.84
Recall (класс "дорогая")	0.79
Дерево решений (классификация)

Модель обучена с ограничением глубины max_depth=5 — без этого ограничения дерево переобучается и хуже работает на тестовых данных.

Метрика	Значение
Accuracy	0.818
Precision (класс "дорогая")	0.84
Recall (класс "дорогая")	0.78

Результат почти сравнялся с логистической регрессией (0.819).

Важность признаков (дерево решений)
Признак	Важность
sqft (площадь)	0.639
year_built (год постройки)	0.232
garage	0.045
baths	0.032
остальные признаки	< 0.02 каждый

Площадь и год постройки вместе объясняют около 87% решений дерева — остальные признаки (тип недвижимости, количество ванных и т.д.) играют второстепенную роль, отчасти из-за того, что редкие категории (farm, apartment) представлены слишком малым числом примеров.

Использованные библиотеки
pandas, numpy — обработка данных
matplotlib — визуализация
scikit-learn — модели машинного обучения (LinearRegression, LogisticRegression, DecisionTreeClassifier, StandardScaler, train_test_split, метрики)
